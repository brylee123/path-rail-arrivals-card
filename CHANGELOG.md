# Changelog

## 1.1.0 (unreleased)

- Align adjacent cards with consistent title space, equal arrival rows, and a footer at the bottom.
- Reserve empty prediction slots without inventing arrivals, so missing trains do not shift the ticker.
- Add minimum row height and minimum card height options to the visual editor.
- Size text using the card width and update the masonry height estimate.

## 1.0.0

- Destination arrival rows with feed-provided train colors and support for multi-color predictions.
- Single-direction and bidirectional layouts with a visual configuration form.
- Automatic, light and dark appearance.
- Station-relevant and general PATH notices in a scrolling alert ticker.
- Explicit unavailable-source messages, keyboard support and reduced-motion handling.
